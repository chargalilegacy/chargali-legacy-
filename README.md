# Chargali Legacy (ჩარგალი ლეგასი)

Independent private development and cultural initiative in **Chargali village, Pshavi** (Dusheti Municipality, Mtskheta-Mtianeti, Georgia), connecting nature, mountain hospitality, family heritage, and Georgian literary adaptations.

## Key Highlights
- **Location:** Chargali, Pshavi, Georgia (~1,200 m above sea level, ~80 km from Tbilisi)
- **Phase I:** Cottage plots (~200 m²) and individual partnership/investment inquiries
- **Long-Term Vision:** Mountain hospitality, nature & recreation (including the Botsakhi direction), family memory & Razikashvili genealogy, local produce, and partnerships
- **Literary Initiative:** Narrative adaptations inspired by Vazha-Pshavela (*Host and Guest* and *The Fawn’s Tale* / *Uyun Al-Ghazal*)
